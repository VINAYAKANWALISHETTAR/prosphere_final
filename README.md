# ProSphere Digital Hub

A TanStack Start website for ProSphere security, testing, maintenance, technical support, and DigiCrystal creative automation services.

## Development

```sh
npm run dev
```

## Verification

```sh
npm run lint
npx tsc --noEmit
npm run build
```

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
